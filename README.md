## Setup
**Important!** 
For this app to work, you need to use your own API key from [FragellaAPI](https://api.fragella.com/) and add it to /backend/.env (you'll need to create a new file with `FRAGELLA_API_KEY={Your key here}`).

Inside the directory "backend", start the server:

```bash
python main.py
```

Then, inside the directory "frontend", run:

```bash
npm run dev
```
Once both are running, open  http://localhost:5173/ to access the application.
